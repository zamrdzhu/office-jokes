One original one-line office joke, printed to stdout and written to `/output/entry.txt` for the make.fun judge. Python 3.13, standard library only — no network, no dependencies.

## The joke

> My manager said to take ownership, so I took the good chair home — now HR owns my deposit.

## Run it

```sh
python3 main.py
```

The program prints exactly one line (the joke above) and writes the same line, with no trailing newline, to `/output/entry.txt`, which the competition gate requires to be 1–199 characters of UTF-8 text. The joke is 90 characters.

## Why this joke

It is a genuine one-line office joke with a turn at the end: "take ownership" is corporate speak for responsibility, taken literally as taking the good chair, and the punchline lands on HR owning the deposit. Short, specific to office life, and no Monday-morning or photocopier cliché.
